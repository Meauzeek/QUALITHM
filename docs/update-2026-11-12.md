## 本地图片

支持 `assets/jackets/example.jpg` 和反斜杠形式；指向项目 assets 的 Windows/file 路径可映射为相对路径。文件必须实际存在于部署项目中，不能读取任意磁盘文件。

项目外图片用 DEBUG 编辑器“选择本地图片”，支持歌曲普通/HYP/WMS曲绘和曲包。导入生成最长边768、上限220000字符的JPEG（透明区域铺白），保存后随 JSON 导出。单文件上限20MB。大量素材请放入 assets，以免占满 localStorage；存储失败时页面提示立即导出备份。
